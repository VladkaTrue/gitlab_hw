### Задание 1


Опишите основные преимущества использования масштабирования методами:

-   активный master-сервер и пассивный репликационный slave-сервер;
-   master-сервер и несколько slave-серверов;

_Дайте ответ в свободной форме._

1.  **Активный master-сервер и пассивный репликационный slave-сервер**:
    
    -   **Отказоустойчивость**: В случае сбоя master-сервера, один из slave-серверов может быть быстро переключен на роль master, обеспечивая непрерывную работу системы.
        
    -   **Распределение нагрузки**: Slave-серверы могут обрабатывать запросы на чтение, снижая нагрузку на основной master-сервер и улучшая производительность.
        
2.  **Master-сервер и несколько slave-серверов**:
    
    -   **Высокий уровень отказоустойчивости**: При выходе из строя одного из slave-серверов, остальные продолжают функционировать, обеспечивая надежность системы.
        
    -   **Балансировка нагрузки**: Запросы на чтение могут распределяться между несколькими slave-серверами, что позволяет более эффективно использовать ресурсы и ускоряет обработку запросов.
        
    -   **Масштабируемость**: Добавление дополнительных slave-серверов позволяет легко увеличивать производительность системы по мере роста нагрузки.

Разработайте план для выполнения горизонтального и вертикального шаринга базы данных. База данных состоит из трёх таблиц:

-   пользователи,
-   книги,
-   магазины (столбцы произвольно).

Опишите принципы построения системы и их разграничение или разбивку между базами данных.

_Пришлите блоксхему, где и что будет располагаться. Опишите, в каких режимах будут работать сервера._
